# Interactive Birthday Story Website

A clean, responsive, interactive first-person (POV) birthday surprise website built purely with vanilla HTML, CSS, and JavaScript.

## Folder Structure
```
├── index.html       # Main webpage and storyline container
├── css/
│   └── style.css    # Responsive styles, glowing animations, 3D card flips
├── js/
│   └── script.js    # Scene controller & zero-dependency confetti engine
└── assets/          # Add your optional background music or custom images here
```

## How to Deploy to GitHub Pages (100% Free)
1. Extract this zip file.
2. Create a new public repository on GitHub (e.g. `happy-birthday`).
3. Upload `index.html`, `css/`, and `js/` folders into the root of the repository.
4. Go to **Settings** -> **Pages**.
5. Under **Branch**, select `main` and `/ (root)`.
6. Click **Save**. Your site will be live at `https://<username>.github.io/<repo-name>/`.
